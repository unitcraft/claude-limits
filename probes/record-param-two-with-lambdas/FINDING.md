# Запись-параметр в двух лямбдах, каждая под своим `with`: в C необъявленный `_box_<имя>`

**Замер 2026-10-01, 20:56.** Реестр 221.1 **№1559** (номер дал интегратор 20:56). Найдено
при T2.27 (`record_round` в `src/claude_limits.nv`, ветка `loop-rounds`): две записи в
базу подряд, каждая — `with Fs = …, Random = … { with_real_db(fn() … => …(paths, …)) }`.

падает компиляция C.

Ось — сочетание: параметр (не локал), ДВЕ лямбды, у каждой СВОЙ `with`. Похоже, вторая
ссылается на бокс параметра, объявленный в области первого `with`. Параметр `bool` рядом
(`win` в `record_round`) захватывается нормально — в C строка `= win`, а не `= _box_win`.

## Обход в claude-limits
