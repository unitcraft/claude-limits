# №TBD — `export const` теряет префикс модуля в C, и два модуля с одним именем не собираются

**Замер 2026-09-13 19:43**, окно плана 01, пакет `claude-limits`. Найдено при написании
`usage/fetch.nv` (T1.5): и модуль, и его тест объявили `const CRLF`.

Репро — десять строк, лежат рядом (`a_lib` и `b_red_same_name_in_two_modules_test`, с расширением `.nv.txt`):

```nova
// lib.nv
export const MARK = "FROM-LIB"
export fn who() -> str => MARK

// lib_test.nv
import lib.{who}
const MARK = "FROM-TEST"
fn mine() -> str => MARK
```

```
error: use of undeclared identifier 'MARK'
```

## Что именно происходит

**Приватная константа получает в C имя с префиксом модуля, экспортированная — голое
имя.** Видно по двум прогонам одного и того же файла:

| объявление | имя в C |
|---|---|
| `const CRLF` | `Nova_const_usage_fetch_CRLF` |
| `export const CRLF` | `CRLF` |

Потому второй модуль, объявляющий то же имя, сталкивается: его собственные обращения
уезжают на чужой символ, а чужой в этой единице трансляции не объявлен.

## Хорошая половина: падает ГРОМКО

Сборка ломается. Это важно сказать, потому что тот же механизм МОГ БЫ дать молчаливую
подмену значения — если бы чужой символ в этой единице оказался объявлен, обращение
ушло бы на него, и `MARK` вернул бы чужую строку без единой диагностики. Сегодня так не
выходит; полагаться на это не стоит, но severity сейчас — «не собирается», а не
«работает неверно».

## Обход

Переименовать одну из констант. В `fetch_test.nv` константа названа `EOL` — шестнадцать
употреблений, правка механическая. **Обход дешёвый и потому опасный:** он выглядит как
стилевая придирка («не называйте одинаково»), тогда как на деле это обход дефекта, и
без этой записи следующий столкнётся с ним как с загадкой.

## Родня

**Четвёртый случай за сутки** «зелёный `nova check` при красной сборке», и все четыре —
о расхождении между тем, что объявлено, и тем, что выпущено:

* №1082 — `@field` у получателя-суммы не резолвится чекером;
* `Result[<псевдоним указателя>, <сумма>]` инстанцируется как `Result[int, str]`;
* `Chan[T]` не выпускает `ChanTx`/`ChanRx` при указательном `T`;
* этот — экспортированная константа теряет пространство имён.

Одна это причина или четыре — **окно не решает**; сказано только видимое.
