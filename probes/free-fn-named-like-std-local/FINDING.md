## Что происходит

В единице есть свободная функция `sec` (`shapes.sec(name str) -> Section`). В std
`Timestamp @to_zoned` (`std/src/time/civil/zoned.nv:275`) есть локальная `ro sec = if rem0 < 0
{ sec0 - 1 } else { sec0 }`. В сгенерированном C у `to_zoned` после этого:

```c
void* _nv_if_1091; ... void* day = _nv_if_1091;          /* было бы int64_t */
void* sod = _nv_if_1092;
Nova_TimeOfDay_static_from_nanos_of_day((0));            /* `sod * 1_000_000_000 + subnano` стало литералом 0 */
```

— время суток любого момента обнуляется.

| проба | ожидание | получено |
|---|---|---|
| `q_free_fn_named_like_std_local` (с `shapes.sec`) | `2026-10-02T17:29:28Z` | **`2026-10-02T00:00:00Z`** |
| то же без модуля `shapes` (КОНТРОЛЬ, отдельная проба тем же днём) | `…T17:29:28Z` | `…T17:29:28Z` |

## Где ударило (claude-limits)

`config_reference.nv` (импорт конфига эталона) завёл `fn sec(...)`. Бинарь стал отдавать все моменты
снимка как `…T00:00:00Z`: время снимка, сбросы окон, подписи «03:00 (0m)» на странице владельца.
Юнит-тесты не видели — ни одна тестовая единица не держит и этот модуль, и время. Обход —
переименование (`section_of`); сторож — проверка `moment` в `scripts/smoke_server.py` (живой бинарь:
`fetched_at` обязан быть «сейчас»; на сборке со старым именем — FAIL, `00:00:00Z`).
