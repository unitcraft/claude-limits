# Находка: это ВТОРАЯ проба одной пары — вывод живёт рядом

**Дата:** 2026-09-08. **Полная находка:**
[`../brotli-shim-link/FINDING.md`](../brotli-shim-link/FINDING.md) — там класс,
вывод линковщика дословно, контроли и что это значит.

Коротко, чтобы читатель, открывший этот каталог, не оставался ни с чем: пакет,
объявляющий `[ffi] c_shims`, получает свой шим скомпилированным, когда он **прямая**
зависимость, и НЕ получает, когда он **транзитивная**. Отсюда четыре
`undefined symbol: compress_brotli_dec_*` при сборке чего угодно, что зовёт
HTTP-клиент.

## Зачем нужна ОТДЕЛЬНАЯ вторая проба

Первая (`brotli-shim-link`) берёт `compress` **прямой** зависимостью и зовёт
`brotli_decode` сама. Эта берёт только `http` и делает самый простой возможный
вызов — один `GET`, без заголовков, без JSON, без файлов, к порту 9, куда никто не
слушает. Запрос НЕ должен пройти; вопрос ровно один — **слинкуется ли**.

Пара нужна потому, что первое утверждение было недостаточно острым, чтобы по нему
действовать: «HTTP-клиент не линкуется» и «шим транзитивной зависимости не
собирается» — разные диагнозы с разной починкой. Две пробы разводят их: прямая
зависимость линкуется, транзитивная нет, и разница — единственное, чем они
отличаются.

Этот файл заведён 2026-09-08 отдельной правкой: каталог пробы стоял без вывода, а
проба без вывода — невидимый долг ровно в том смысле, в каком `AGENTS.md` запрещает
маркер без записи. Вывод не переписан сюда копией: две копии расходятся, и читатель
находит устаревшую.
