### Ф1 — БЫЛА ЖИВА. Починена

**Замер:** из четырёх форм встроенного кода проходили ТРИ.

| форма | было |
|---|---|
| `<SCRIPT>alert(1)</SCRIPT>` | `PAGE GUARD: clean` |
| `<STYLE>body{}</STYLE>` | `clean` |
| `<div onclick="alert(1)">` | `clean` |
| `<script data-src="x">` | поймана, но ДРУГИМ правилом |

Регулярки шли без `IGNORECASE`, а имена тегов в HTML регистронезависимы. Обработчиков
событий не искал никто — а это скрипт, записанный иначе.

Четвёртая форма ловилась случайно: правило локальных ссылок жаловалось, что файла `x`
нет. Подставь существующий файл (`data-src="app.js"`) — и она проходила бы молча.
`\bsrc=` совпадает внутри `data-src=`, потому что дефис — граница слова, поэтому
отрицательный просмотр читал скрипт с посторонним атрибутом как внешний.

**Починка:** `re.I` на обоих правилах, `src` сверяется как ЦЕЛЫЙ атрибут
(`(?<![-\w])src`), и список из двадцати обработчиков событий. Не `on\w+=` шаблоном:
он задел бы законные атрибуты у пользовательских элементов.

**Проба в обе стороны:** все четыре формы теперь отвергаются поимённо, настоящая
страница — `clean`.

### Ф11 — БЫЛА ЖИВА, и за ней стояла НЕПОСТРОЕННАЯ ЧАСТЬ СТРАНИЦЫ

`haystack()` склеивал ВЕСЬ исходник, и подпись считалась «производимой страницей»,
если её буквы нашлись где угодно. Нормализатор съедает точки, поэтому
`bar.style.width` превращается в `bar style width` и содержит `bar style`.

**Замер до правки:** из 149 подписей ЧЕТЫРЕ держались на мусоре — ровно те, что
назвал охотник, и ни одной больше:

```
Layout      <- layoutCells
Bar style   <- bar.style.width
Rounded     <- "in a rounded panel" (комментарий)
Blocks      <- "Only a 429 blocks it." (комментарий)
```

**Починка стража:** сверка по строковым ЛИТЕРАЛАМ и тексту разметки, с вырезанными
комментариями. Подпись, которую страница правда рисует, живёт в литерале;
идентификатор — нет, и проза о коде — нет. Части склеиваются через `\x00`, чтобы
совпадение не могло лечь на шов двух чужих строк.

**А дальше начинается настоящее.** Страж покраснел на четырёх подписях, и они не
ложные: `01.1:298-299` требует «Layout `List / Cards`» и «Bar style
`Rounded / Blocks`», обе в `localStorage`. В `settings.js` этих элементов НЕ БЫЛО
вовсе — при том что `BROWSER_ONLY` уже называл `view` и `bar_style`, то есть половина
проводки их ждала.

**Построены оба** — новым элементом `choice` (два варианта, `role="radiogroup"`,
стрелки по §10), через ту же дверь браузерных настроек, что сделана сегодня для
`countdown`. `collect` их пропускает, `collectBrowser` собирает, `saveBrowser` пишет.

Страж после постройки: `chrome labels unaccounted: 0`.
