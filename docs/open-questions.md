# Открытые вопросы

Что ждёт решения владельца. Решённое — вычёркивается с датой и ссылкой на коммит.

## Две штриховки одной строки красятся по разным шкалам (2026-10-08)

Вопрос владельца по скриншоту Codex: сверху жёлтая штриховка, снизу зелёная до конца окна.

- Штриховка толстой полосы красится по проценту на сброс (`forecast.severity`): зелёный до 80%,
  жёлтый с 80%, красный с 95% (`[forecast]` в настройках).
- Штриховка тонкой линии красится по моменту исчерпания (`runsOutTone` в `src/web/format.js`):
  зелёный, если лимит доживает до 95% окна, жёлтый с 80%, красный раньше.
- Поэтому при прогнозе 85% верхняя жёлтая, нижняя зелёная; при 97% верхняя красная при зелёной
  нижней: лимит до 100% не дойдёт, а верх красный.

**Вариант:** красить верхнюю так же, как нижнюю (красная только когда лимит реально кончается
раньше окна). Правка в `src/web/render.js` и `src/web/format.js`, плюс тесты в
`scripts/test-render.mjs`.

**Умолчание:** оставлено как есть; README описывает как есть.
