# Дизайн страницы в браузере

Макеты страницы, которую бэкенд `claude-limits` отдаёт на `127.0.0.1:7391`.
Утверждены владельцем 2026-09-06. Живой холст с возможностью правки:
https://claude.ai/code/artifact/620932c4-2769-411e-9752-cb27c42d43cf

Каждый `*.dc.html` здесь — один артборд холста и одновременно эталон разметки
для `web/index.html` (план, §3.3). Раскладка холста — `canvas.json`.

## Решения, влияющие на реализацию

**Тема.** Токены сайта Nova (`www/site/src/styles/global.css`, тёмная схема), усиленные:
фон `#13111d` с двумя мягкими фиолетовыми свечениями (`rgba(107,63,160,.30)` слева
сверху, `.16` справа снизу), плашка `#1e1a2e`, альтернативная поверхность `#181526`,
границы `#322c4a` / `#3b3458`, подложка бара `#2a2542`, текст `#e8e8ee`, приглушённый
`#9b95b5`, тихий `#6d6786`. **Акцентный фиолетовый на кнопках не используется**,
подкрашены только поверхности. Шрифты сайта: Manrope для интерфейса, JetBrains Mono для
чисел, времён и путей.

**Цвета состояний.** normal `#3aa98c`, warning `#e0b04a`, critical и locked `#e0554f`,
stale/нет данных — серые. Учётка с любым окном на 100 % получает красноватую плашку:
фон `#2f1a2e`, граница `#56304c`, подложки баров `#3d2438`.

**Три вида** переключаются в шапке: список, плашки, статистика. Плашки перетаскиваются за
ручку слева, порядок сохраняется в конфиг и действует во всех видах.

**Бар: два стиля** (настройка «Bar style»). Закруглённый — по умолчанию. Кубики: шаг
10 px (ячейка 8 + зазор 2), зазор — тот же цвет, затемнённый примерно на 12 %; скруглены
только внешние края; **ячейка либо залита целиком, либо пустая**: ширина бара округляется
до целого числа ячеек, заливка — до целой ячейки; точный процент остаётся в числовой
колонке. В CSS это `repeating-linear-gradient` с шагом в пикселях, а не N дочерних
элементов (иначе зазоры получаются неровными из-за дробной ширины).

**Полоса времени.** Под каждым баром расхода тонкая (3 px) полоса цвета `#7a6fa0`: доля
окна, которая уже истекла (5 ч для сессии, 7 д для недельных). Расход впереди полосы —
темп выше, чем позволяет окно. Включается тумблером «Time elapsed bar». Генератор —
`tools/add_timebars.py` (считает долю из строки «(1h 02m)» в колонке сброса).

**Колонки строки лимита**: `название 100px · бар · процент 44px · время сброса 170px`,
процент и время прижаты вправо и не переносятся.

**Статистика.** Три колонки = три окна лимитов: сессия 5 ч, все модели 7 д, по моделям
7 д. Один оттенок на график; в помодельном — две серии с легендой. Пунктирные вертикали —
сбросы окон, красная полоса — блокировка, янтарная — разрыв данных. Наведение — перекрестие
и подсказка «время · процент». Группировка «по папкам»: папка с кредами = место человека,
в ней сменяются учётки; полоса над графиками показывает, кто когда был залогинен, линии
берут цвет учётки и обрываются в момент смены. Палитра учёток `#3aa98c` / `#a27bd0` /
`#cf6f4a` проверена валидатором на различимость при цветовой слепоте на поверхности
`#1b1b26`. **Ограничение**: эндпоинт считает на логин, поэтому две папки под одной учёткой
одновременно показывают одну кривую.

**Настройки.** Вид, стиль бара, обратный отсчёт, скрытие протухших; **папки с кредами —
добавить (путь или Browse) и удалить**, у каждой строки написано, что в ней найдено;
порядок учёток; интервал с полом 60 с; пороги; адрес сервера с выключенным доступом из
сети; тумблеры виджета.

Что из этого требует от бэкенда больше, чем было в плане до дизайна: история замеров
(кольцевой буфер, 5 мин, 30 дней) и `/api/history`; журнал «какая учётка сидела в папке
когда»; запись в конфиг не только `[widget]`, но и папок, порядка, вида и стиля бара по
действиям пользователя в интерфейсе.

## Как пересобрать холст

Графики статистики генерируются, не правятся руками:

```
python tools/gen_stats.py     # StatsView.dc.html и StatsFolders.dc.html в токенах первого раунда
python tools/retheme.py       # перевод всех тёмных артбордов в токены Nova (идемпотентно)
python tools/add_timebars.py  # полосы времени под барами в Main и CardsView + пересборка MainBlocks (идемпотентно)
```

Порядок обязателен: генератор пишет старые токены, `retheme.py` переводит их. Остальные
артборды правятся прямо в файлах. Сборка холста и публикация — через `/design` в Claude Code
(артборды, `canvas.json`); собранный `claude-limits-browser-page.html` весит около 3 МБ и в
git не хранится.

Все почты, организации, проценты и времена в макетах вымышленные.
