**Редакция 1.0, 2026-09-07.** Подплан плана [01-widget-on-nova.md](01-widget-on-nova.md): фазы Ф.0–Ф.4
разложены на задачи, пригодные для исполнения по одной, в том числе агентами на дешёвых моделях.
Правила исполнения, окружение, формат отчёта — [executor-brief.md](../executor-brief.md); карточка
ссылается на разделы подпланов, а не пересказывает их. Ф.5 и Ф.6 (после релиза) здесь не
разложены: их состав — план 01 §6.

Обозначения: размер S ≤ 2 ч, M ≤ 4 ч, L ≤ день; модель — минимальная достаточная (бриф §4).
«Готово, когда» — команды из корня пакета через обёртку `./nova.sh` (T0.0). Каждая задача
завершается отчётом `docs/reports/<id>.md` (бриф §6) и одним коммитом.

Порядок внутри фазы — сверху вниз, если не указано иное; задачи без общих зависимостей можно вести
параллельно (отмечено ∥).
