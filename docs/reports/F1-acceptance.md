## Команда дифференциала и её вывод

```
$ python scripts/diff_with_probe.py --offline fixtures/usage \
    fixtures/dirs/expired fixtures/dirs/default-layout/.claude \
    fixtures/dirs/config-dir-layout/work \
    fixtures/dirs/two-dirs-one-account/same-email-a \
    fixtures/dirs/two-dirs-one-account/same-email-b
SAME: 14 comparable lines agree (offline, 5 directories)
```

**Почему это не пустой зелёный, и это проверено, а не заявлено.** Тот же стенд на
каталоге без логинов отвечает отказом, а не согласием:

```
$ python scripts/diff_with_probe.py --offline fixtures/usage fixtures/dirs/no-login
CANNOT COMPARE: neither side produced a single comparable line.
  ...
  Exit 2, not 0: an empty comparison is not an agreement.
```

Эта клетка была ДЫРОЙ до 2026-09-13: две пустые стороны давали `a == b` тривиально и
печатались как `SAME: 0 comparable lines agree` — с нулём на виду. Стенд — механизм
приёмки всей фазы, и наведённый на обычный каталог без учёток он заверял бы фазу,
не сравнив ничего.

## Чего фаза НЕ узнала

**1. Строка 429 неотвечаема, и цепь известна.** Требование — «фикстура 429: одинаковая
строка состояния у обеих программ». Фикстуры лежат в `fixtures/transport/`
(`rate-limited-with-retry-after.json`, `rate-limited-no-header.json`), и их собственный
README называет потребителя: **«входы для `usage/fetch.nv` (задача T1.5)»**. Этого файла
в дереве нет:

```
$ ls src/usage/
parse.c  parse.nv  parse_test.c  parse_test.nv
```

`fetch.nv` стоит за реестром **№1033** (шим `nova-compress` не линкуется у потребителя)
— тем же блокером, что держит спайк T0.2 и карточку T0.6 в фазе Ф.0. Кроме того, офлайн
дифференциала подаёт **тело ответа**, а не статус с заголовками: даже при наличии
`fetch.nv` эту строку пришлось бы отвечать не стендом, а тестом с мок-`Http`.

Это не «ещё не взялись», а цепь: **Ф.1 429 ← T1.5 `fetch.nv` ← №1033**, и первое звено
чужое.

**2. `--live` не запускался ни разу.** Дифференциал офлайновый по умолчанию, и это
решение фазы («2026-09-07 машина так заработала 429»). Значит совпадение доказано на
записанных ответах; поведение на живом эндпоинте этой приёмкой НЕ проверено.

**3. Три расхождения, найденные и снятые по дороге** — записаны здесь, потому что каждое
жило в зелёном дереве: логин без файла личности пропадал молча; `login_at` не видел
личность рядом с `.claude` (куда указывает `CLAUDE_CONFIG_DIR`); группировка шла внутри
каждого каталога, и одна учётка на две папки распадалась надвое. Все три в `4f91c3d`.

## Что считается доказательством

Каждая строка выше — команда и её вывод, а не чтение кода, **кроме** одной, помеченной
«чтение кода стенда»: «одни и те же записанные ответы» — свойство стенда, а не
наблюдаемый результат, и проверяется оно чтением `diff_with_probe.py:106-107`, где список
флагов строится ОДИН раз и подставляется обоим вызовам (строки 109 и 122).
