# 9 — уведомления о порогах в браузере
Сделано: `src/web/notify.js` — чистая `planNotifications(limits, told, {enabled, now, names})`: пороги 70 и 90 фиксированные; ключ (учётка, окно, модель, resets_at, порог) → после сброса окна пороги взводятся заново; скачок через оба порога даёт одно уведомление (90), 70 помечается как отправленное; выключено — молчит и ничего не записывает; locked-окна не объявляются (решение по умолчанию); записи старше суток после сброса забываются. `app.js`: `notifyThresholds` после каждого снимка читает localStorage (`notify`, `notified`), зовёт функцию и показывает `Notification` (только при granted); кнопка «Allow notifications» запрашивает разрешение. `settings.js`: переключатель «Notifications» (browser-store, по умолчанию выкл, `notify` добавлен в BROWSER_ONLY), строка состояния разрешения.
