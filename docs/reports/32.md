этот проход не засчитывается как upgrade. После остановки импортируются две записи

её и проверяет exact rows. До и после смены config на противоположный storage mode сравнивает полный список

режима повторный запуск исходного режима обязан вернуть те же две записи. E2E отрицательная
проба сохраняет только synthetic DB, WAL, generated key и backup files; удаляет account/history
