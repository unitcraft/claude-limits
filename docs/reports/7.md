Отклонения от входов:
  - Карточка просит keep-alive «раз в ~15 с — комментарием». 01.3 §3.4 и 01.1 §9 — событие `ping`
    `{ "at": … }` раз в 30 с при тишине, и страница слушает именно событие (комментарий его не
    вызывает, см. историю в `sse_loop.bytes_of`). По брифу задачи — спецификация первична: сделано по
    01.3.
  - Ушедший клиент снимается со счётчика не мгновенно, а за ~2 мин: у Polaris нет хука «клиент
    ушёл», store узнаёт об этом по `STALE_BACKLOG` непрочитанных событий на тике пинга (так было и
    раньше; теперь это видно в `sse_clients`).
  - Строку roadmap не удалил, а отметил `[x]` без оговорки про SSE: удаление стёрло бы пункт о
    бэкенде целиком.
  Схема БД не тронута. Контракт API не менялся: поля и события — как в 01.3, `sse_clients` из
  заглушки стал честным, `ping` начал подчиняться «при тишине»; чек-лист API §20 по форме не
  затронут (новых маршрутов, полей, кодов нет), БД §17 не применим.
