# #31 — Целые ячейки при каждом обновлении полос

Сделано: после каждого обновления карточек применяются уже существующая canonical-cell geometry и её forecast/timebar overlay. На скрытом view с нулевой шириной пиксельная геометрия не затирает проценты; при возвращении view layout пересчитывается. Не менялись процентная семантика, API, схема, база, конфиг или CSS-grid из #30.

Root cause подтверждён на базе `9aee790e5f7a1d528bd322889d049bd806d0f9f9`: `renderList` перекладывал ячейки после snapshot replace, а unified `renderCards` — нет. Новые fills в Blocks оставались в исходной `%`-ширине до resize/style change. Дополнительная проверка показала, что общий `layoutCells` при скрытом view мог бы записать `0px`; теперь он пропускает его, а `showView` перекладывает после reveal. Fixed 8px cell + 2px gap, canonical `data-percent`, reversible geometry и timebar alignment из #28/#30 сохранены.
