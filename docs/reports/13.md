# 13 — Шифрование БД опционально, по умолчанию без ключа

Сделано: `storage.encrypted` — bool=false в defaults, TOML и публичном JSON API.
Все открытия используют закреплённый при старте режим. Plain не обращается к ключу;
encrypted создаёт ключ только при стартовом отсутствии DB и WAL. Повторные операции
не генерируют ключ. Backup/compaction получают тот же режим через ключ открытия.
Health: false/none или true/file. README, пример и планы обновлены.
