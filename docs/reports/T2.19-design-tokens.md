## Чего в источниках нет

- объявления CSS custom properties (`--имя: значение` / `var(--имя)`) — не найдено в Main.dc.html: все цвета заданы литеральными hex/rgba инлайн в `style=` и в единственном блоке `<style>`; имена переменных для этой карты взяты только из спеки §8.
- визуальное подтверждение `--surface-hover` (`#25203a`) — не найдено в Main.dc.html (в статичном макете нет состояния наведения).
- визуальное подтверждение `--border-strong` (`#3b3458`) — не найдено в Main.dc.html.
- визуальное подтверждение `--series-2` (`#a27bd0`) и `--series-3` (`#cf6f4a`) — не найдено в Main.dc.html (артборд `Main.dc.html` — вид «список», без графиков статистики).
- применение начертания Manrope `700` — не найдено ни в одном инлайн-стиле Main.dc.html, хотя шрифт подключён с этим начертанием (строка 10).
- letter-spacing — не указано ни в Main.dc.html, ни в спеке §8/§1.
- имя переменной для приглушённых цветов текста внутри красной (locked) плашки (`#d9c9dc` и `#ab98b4`, см. раздел «Расхождения») — не названо ни в Main.dc.html, ни в спеке §8.

## Расхождения между артбордом и спекой

- подпись подвала справа: артборд говорит «`every 300 s · next 19:52`» (Main.dc.html, строка 146), спека §1.2 говорит «`polling every 300 s · next 19:52`» — слово «polling» в артборде отсутствует.
- цвет названия окна лимита (`--fg-soft`) внутри красной (locked) плашки: артборд говорит «`#d9c9dc`» (Main.dc.html, строки 95, 101 — подписи `session 5h` и `all 7d`), спека §8 говорит «`--fg-soft` = `#cbc7da`» без отдельного варианта для locked-плашки.
- цвет подписи организации/времени (`--fg-muted`) внутри красной (locked) плашки: артборд говорит «`#ab98b4`» (Main.dc.html, строки 85, 98, 104), спека §8 говорит «`--fg-muted` = `#9b95b5`» без отдельного варианта для locked-плашки.
- начертания шрифта Manrope: артборд подключает «`Manrope:wght@400;500;600;700`» (Main.dc.html, строка 10, четыре начертания), спека §8 говорит «Manrope 400/500/600 для текста» (три начертания).
