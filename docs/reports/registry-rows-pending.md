## №1033 — линковка

| 1033 | 🔴 К1 | **НИ ОДИН ПАКЕТ, ЗОВУЩИЙ HTTP-КЛИЕНТ, НЕ ЛИНКУЕТСЯ: C-ШИМ `nova-compress` НЕ СОБИРАЕТСЯ, ЧЕТЫРЕ НЕРАЗРЕШЁННЫХ СИМВОЛА.** Найдено 2026-09-08 окном claude-limits при сборке спайка T0.2 (план 01 Ф.0 п.2). Вердикт дословно: «`lld-link: error: undefined symbol: compress_brotli_dec_new`», то же для `compress_brotli_dec_pull`, `compress_brotli_dec_done`, `compress_brotli_dec_needs_input`, далее «`clang: error: linker command failed with exit code 1`». Все четыре — функции из `nova-compress/native/compress_shim.c`. **НОСИТЕЛЬ МИНИМАЛЕН И ЭТО ГЛАВНОЕ:** `probes/http-client-link/` в репозитории claude-limits — четырнадцать строк Nova, единственная зависимость `http`, один `GET` без авторизации и заголовков, никуда не отправляемый; падает так же. Приёмка: (1) названо и зафиксировано ИЗМЕРЕННОЕ различие между `tls` и `compress` в этом графе; (2) фикстура-пакет, транзитивно достигающая шима зависимости, собирается и линкуется; (3) обратная проба — снять условие фикса, увидеть те же четыре неразрешённых символа. **МАРШРУТ: ЧИНИТСЯ:** сборочный конвейер `[ffi]` (компилятор/CLI) либо `nova-compress`; сторона выбирается по результату пункта (1) приёмки. Для плана 01 это блокер Ф.1 целиком: опрос эндпоинта и есть вся фаза. **Статус:** ОТКРЫТА 2026-09-08 — заведена окном claude-limits, номер интегратора. |
