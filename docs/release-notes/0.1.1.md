# claude-limits 0.1.1

This maintenance release improves browser settings, account ordering, bar rendering,
and storage safety. Windows x64 only.

## What's changed

- Browser settings now take effect immediately, and Accounts and Reorder use a unified
  account view.
- Blocks are rendered as whole, aligned cells after reloads, live updates, and when a
  hidden view is revealed.
- New data is stored unencrypted by default. Database encryption is opt-in; startup
  refuses unsafe access when an encrypted database's key is missing.
- History recovery/import verification and synthetic storage-mode checks are available
  to help validate existing data safely.

## Upgrade and data safety

- Back up your database and settings before upgrading.
- Existing databases and encryption keys are not deleted or replaced by this release.
- Existing plain databases remain plain and retain their history. New databases are
  plain by default; enable encryption only if you have a safe key-management plan.
- Losing an encryption key can make encrypted history unreadable; this release cannot
  recover a lost key. Keep a separate, secure backup of the key and database.

No API version or database schema change is included in this release.
